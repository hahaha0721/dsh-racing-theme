# dsh-racing-theme

F1 赛车风格的 DeepSeek Harness 主题插件：碳纤维背景、官方风格 F1 水印（红色辉光呼吸 + 周围碳纤维同步照亮）、赛车红强调色。

## 安装

```bash
dsh plugin --profile web add git+https://github.com/hahaha0721/dsh-racing-theme.git
# 重启 dsh web 生效
```
